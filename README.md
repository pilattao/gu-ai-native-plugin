# Green Unicorn · AI-Native

Маркетинг, Финансы и Юрист работают как навыки в текущем разговоре Claude.
Плагин содержит правила Green Unicorn и выбранные методики; корпоративные данные
доступны через отдельное подключение `gu-core` после вашего входа.

Plugin: gu-ai-native-stage

Core URL: https://stage.ai.greenunicorn.bh/mcp

Это предварительный выпуск для stage. Доступность marketplace, установка,
автообновление и рабочее подключение проверяются отдельно. Успешная сборка
не подтверждает прохождение этих проверок.

## Установка в Claude

1. Откройте **Customize → Plugins → Add → Add marketplace**.
2. Укажите `https://github.com/pilattao/gu-ai-native-marketplace`.
3. Выберите плагин из строки **Plugin** выше и нажмите **Add** или **Install**.
4. Для marketplace включите **Sync automatically**, если этот переключатель доступен.
5. В установленном плагине откройте **Connectors → gu-core**. Если подключение
   ещё не добавлено, нажмите **Add**, затем **Connect** и пройдите корпоративный OAuth-вход.
   Существующее подключение используйте после проверки точного адреса Core.
6. Начните новый разговор и убедитесь, что навыки и инструменты `gu-core` доступны.
   Агент проверяет `get_started`, `whoami` и ожидаемую учётную запись по вашему
   персональному промпту из корпоративного портала.

Публичный marketplace не требует GitHub-аккаунта сотрудника или токена в промпте.
Если клиент всё же требует GitHub-доступ, сохраните текст ошибки и передайте его
ответственному за подключение. Не передавайте пароли, cookies и токены агенту.

В поддержанном профиле Core разрешение MCP — `mcp:access`. Оно разрешает соединение,
а доступ к операциям и данным ограничивают ваши роли и ACL в Core и Google.
На экране OAuth проверьте запрошенные разрешения; выданные MCP scopes агент
проверяет через `whoami`. Дополнительный вход не означает согласия на бизнес-записи.

Для поддержки откройте [Мои заявки](https://stage.ai.greenunicorn.bh/?view=feedback)
в корпоративном портале и нажмите **Создать заявку**. Укажите версию плагина,
текст ошибки и время; не прикладывайте токены или содержимое рабочих документов.

## Работа с плагином

| Навык | Задачи |
|---|---|
| `finance` | Управленческие отчёты, план-факт, экономика проектов, модели и расчёты |
| `marketing` | Позиционирование, материалы, кампании и отчётность |
| `legal` | Договоры, правовые риски и документы для экспертной проверки |

Общие [правила GU](references/gu-policy.md) и [порядок работы](references/workflow.md)
применяются ко всем направлениям. Методики выбираются через адаптеры в текущем
разговоре; смена направления не создаёт отдельного агента или подключения.
Изменения инструкций перечислены в [release notes](references/release-notes.md).

В совместимом Core вы выбираете личные и корпоративные рабочие папки и выдаёте
разрешение до отзыва. По вашему запросу агент создаёт, загружает и правит файлы
в этих папках без нового подтверждения каждой записи. Постоянных разрешений
на отдельный документ нет. Вход сам по себе такого разрешения не выдаёт.

Для публикации из личной области в корпоративную, расширения доступа, шаринга,
уведомлений, удаления или восстановления целого файла нужна разовая карточка Core.
Она ожидает вашего решения один час; у разрешения на папку таймера нет. Несколько
точно указанных чувствительных действий могут входить в одну карточку. Агент
выполняет каждое действие отдельно после вашего решения и проверяет результат.

Новые результаты агент готовит и проверяет в приватной `ADLC/Outputs`, затем
публикует в выбранную существующую бизнес-папку. Обычную правку выбранного
корпоративного документа можно внести в тот же файл. Личная память остаётся
в личной области и автоматически не публикуется. Содержательная проверка юристом,
финансистом или владельцем результата не заменяет разрешение Core и не создаёт
новую карточку на каждую рабочую запись.

Кандидат 0.1.8 содержит эти инструкции для согласованной модели разрешений.
При скачивании крупных бинарных оригиналов агент использует переданный Core адрес
и проверяет полный размер файла и SHA-256 перед дальнейшей работой.
Доступные способы работы с файлами и форматами агент сверяет с фактическими
инструментами и средой. Подготовка пакета не подтверждает готовность native
Docs/Sheets, production-записи или проверку Claude в веб-, десктопном и мобильном
клиентах; для этого нужны отдельные результаты приёмки.

## Обновление

После обновления начните новый разговор, чтобы проверить загруженную версию.
Номер в списке плагинов сам по себе не подтверждает обновление инструкций старого чата.
Если версии плагина и Core расходятся, агент помогает дождаться обновления и
приостанавливает только действия, которым нужны актуальные инструкции.
Поддерживаемый анализ уже предоставленных данных может продолжаться.

При переходе со stage на production проверьте адрес выбранного коннектора:
одинаковое имя `gu-core` не подтверждает, что выбрано нужное окружение.
