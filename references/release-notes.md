  `urn:gu:file-download` JSON descriptor. Download the original through the exact
  public stage Core GET route with its supplied opaque ticket; keep credentials

Initial upload, safe verification and separately reviewed recovery capability delivery retain exact identity/parent/checksum bindings and unknown/no-reinit rules. Core/Google release bindings, restored native Docs/Sheets methods, deployed format fidelity and live acceptance remain separate gates.
